# References and source data

This project uses published experimental data and literature model parameters.
The digitized/transcribed data used by the scripts are committed in `data/`.
Copyrighted article PDFs are not committed to this public repository.

## Experimental datasets

1. W. Steinhogl, G. Schindler, G. Steinlesberger, and M. Engelhardt,
   "Size-dependent resistivity of metallic wires in the mesoscopic range,"
   *Physical Review B* 66, 075414 (2002).
   DOI: https://doi.org/10.1103/PhysRevB.66.075414

   Repository data:
   - `data/steinhogl2002_fig3_points.csv`
   - `data/steinhogl2002_fig3_curves.csv`

   Source used here:
   - Fig. 3 was digitized for the wire resistivity points and printed model
     curve samples.

2. A. E. Yarimbiyik, H. A. Schafft, R. A. Allen, M. D. Vaudin, and
   M. E. Zaghloul, "Experimental and simulation studies of resistivity in
   nanoscale copper films," *Microelectronics Reliability* 49(2), 127-134
   (2009).
   DOI: https://doi.org/10.1016/j.microrel.2008.11.003

   Public NIST copy:
   https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=32595

   Repository data:
   - `data/yarimbiyik2009_table1_films.csv`
   - `data/yarimbiyik2009_table2_grains.csv`

   Source used here:
   - Table 1 was used for film thickness and resistivity data.
   - Table 2 was used for film grain-size data.
