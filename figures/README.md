# Figures

Generated figures used in `docs/report.md`.

- `benchmark_fig3.png` - reproduction/benchmark of Steinhogl Fig. 3 model
  curves.
- `fit_steinhogl.png` - fitted FS+MS model for the Steinhogl Cu wire data.
- `validate_yarimbiyik.png` - no-refit validation on the Yarimbiyik Cu film
  data using literature parameters.
- `validate_yarimbiyik_transfer.png` - cross-dataset transfer test using the
  Steinhogl-fitted grain-boundary reflection coefficient.
- `sensitivity.png` - one-at-a-time parameter sensitivity analysis.
- `ru_case_study.png` - exploratory Cu-with-liner versus barrierless-Ru
  comparison.

The scripts in `src/` regenerate these files.
