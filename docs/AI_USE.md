# AI-assisted work disclosure

AI tools were used as coding and writing assistants during this project.

Main uses:

- explaining and cross-checking the FS and MS model equations while reading
  the source literature
- drafting and revising documentation and report prose
- helping organize Python scripts and tests
- debugging numerical-code issues and suggesting consistency checks
- checking whether reported numbers, file paths, and figure references were
  internally consistent

The AI tools were treated as assistants, not as authorities. The project
author was responsible for selecting the datasets, implementing and running
the scripts, checking numerical outputs against the source papers and generated
figures, and deciding which physical conclusions were justified.

No experimental data were generated by AI. The data files in `data/` were
digitized or transcribed from the published papers listed in
`docs/references.md`.
