# Data

This directory contains the small literature-derived datasets used by the
analysis scripts.

- `steinhogl2002_fig3_points.csv` - digitized Cu wire resistivity points from
  Steinhogl et al. Fig. 3.
- `steinhogl2002_fig3_curves.csv` - digitized samples of the printed Fig. 3
  model curves used for benchmarking.
- `yarimbiyik2009_table1_films.csv` - Cu film thickness/resistivity data
  transcribed from Yarimbiyik et al. Table 1.
- `yarimbiyik2009_table2_grains.csv` - film grain-size data transcribed from
  Yarimbiyik et al. Table 2.

The original articles are cited in `../docs/references.md`. Copyrighted paper
PDFs are not committed to this public repository.

Generated numerical caches may appear locally under `data/cache/`; that
directory is ignored by Git and can be regenerated by the scripts.
